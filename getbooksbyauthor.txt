# Task 4: Get Books by Author

--- Success Case ---
Command:
curl -s "http://localhost:5000/author/Chinua%20Achebe"

Output (Success - HTTP 200):
[
    {
        "author": "Chinua Achebe",
        "title": "Things Fall Apart",
        "reviews": {}
    }
]

--- Error Case (Author not found) ---
Command:
curl -s "http://localhost:5000/author/Unknown%20Author%20XYZ"

Output (Author not found - empty array):
[]
(Empty array - no books found for this author)
