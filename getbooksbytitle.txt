# Task 5: Get Books by Title

--- Success Case ---
Command:
curl -s "http://localhost:5000/title/Things%20Fall%20Apart"

Output (Success - HTTP 200):
[
    {
        "author": "Chinua Achebe",
        "title": "Things Fall Apart",
        "reviews": {}
    }
]

--- Error Case (Title not found) ---
Command:
curl -s "http://localhost:5000/title/Nonexistent%20Title"

Output (Title not found - empty array):
[]
(Empty array - no books found with this title)
